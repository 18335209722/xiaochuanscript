小川环境助手 · Windows 版 · 使用说明

这个目录里有两种用法，功能相同，任选其一：
  A. XiaochuanEnv.exe（1.0.0，图形界面）：双击运行。
  B. xiaochuan-env.bat + xiaochuan-env.ps1（1.2.0，脚本版）：两个文件要放在同一个目录。
  「关闭系统定位 / Chrome 定位」和「语言包下载限时」只有脚本版有，exe 版还是 1.0.0 的功能。

脚本版运行：
  双击 xiaochuan-env.bat                     交互菜单（输入 a 一键执行）
  xiaochuan-env.bat -All                     直接执行：清缓存 + Chrome + 时区 + 语言 + 关定位
  xiaochuan-env.bat -All -DryRun             演练，只显示将要做的事
  xiaochuan-env.bat status                   检查当前状态
  xiaochuan-env.bat -Help                    全部参数

  脚本会自己弹出 UAC 申请管理员权限（只弹一次，之后所有操作都在管理员权限下执行），
  不需要手动「以管理员身份运行」。当前登录的 Windows 账户必须本身是管理员。

功能：
  1. 清理 Claude Code 缓存、日志、临时文件
  2. 可选清理 Claude Code 会话历史
  3. 清理 Chrome 缓存，把 Chrome 语言设为 en-US，并关闭 Chrome 定位（-Chrome）
  4. 修改 Windows 时区为 America/Los_Angeles（太平洋时间）
  5. 修改 Windows 语言/区域为 en-US，键盘只留美式键盘
  6. 关闭系统定位服务（-Location，脚本版）
  7. 安装 / 卸载 Claude Code 和 Claude Desktop

脚本版的状态检查：
  菜单顶部和每次执行结束后都会显示当前状态：
    √ 表示这一项已经达标，× 表示还没达标。
  时区这一项只有「时区正确」并且「自动设置时区」已关闭才算 √。
  系统定位只有「定位服务」总开关、「允许应用访问你的位置」、
  「允许桌面应用访问你的位置」三个都关了才算 √；
  Chrome 定位要每个个人资料都是「不允许网站查看我的位置」才算 √。

脚本版的执行方式（多种方式逐个尝试 + 执行结果）：
  - 每一项都准备了多种做法：一种不行就自动换下一种，每试一种都读回实际结果核对，
    成功才停。例如时区：tzutil > Set-TimeZone；语言：系统命令 > 直接改注册表；
    删不掉的文件：去只读属性 > rd/del 强删 > 夺取所有权后再删。
  - 每次执行的最后都有一份「执行结果」，对你选中的每一项列出绿色的 √ 或红色的 ×；
    没有完成的项目用红色高亮，并写着「没有完成」。
    最后一行是总结果：全部完成是绿底，有没完成的是红底，并写明有几行没有完成。
  - 没有英文显示语言包时会自动下载安装（需要联网）。这一步放在最后做，
    其余项目都已经完成；最多等 15 分钟，等的时候每 30 秒报一次进度，按 S 可以跳过不等。
    超时或跳过后脚本照常结束，「执行结果」里会用红色写明语言包没装上。
    只下载显示语言包本身，不带语音、手写、OCR 这些附加功能，下载量小很多。

注意：
  - 修改时区、语言需要管理员权限，会弹 UAC；语言需要注销或重启 Windows 后生效。
  - 脚本版会同时关闭「自动设置时区」。
  - 关闭系统定位 = 设置 > 隐私和安全性 > 位置 里的「定位服务」「允许应用访问你的位置」
    「允许桌面应用访问你的位置」全部关掉；天气、地图、「查找我的设备」这类功能会拿不到位置。
    需要时到同一个页面手动打开即可。
  - 关闭 Chrome 定位 = chrome://settings/content/location 改成「不允许网站查看我的位置」，
    以前单独允许过定位的网站也会一并清掉；每个个人资料都会改。
  - 系统区域设置改成 en-US 后，个别老的中文软件可能显示乱码；
    需要时到 控制面板 > 区域 > 管理 > 更改系统区域设置 改回中文。
  - 英文显示语言包如果下载安装失败 / 超时，界面文字仍是中文，其余语言 / 区域设置不受影响；
    网络好了以后重新运行一次，或到 设置 > 时间和语言 > 语言和区域 手动添加 English (United States)。
  - exe 版：Chrome 必须完全退出，否则 Chrome 缓存和语言会跳过。
  - 脚本版：Chrome 在运行时会先自动把它关闭（先正常关闭，标签页下次可恢复；关不掉再强制结束），
    然后再清理和改语言。执行前请先保存好网页里没提交的内容。
  - Chrome 的语言列表会改成只有英文（en-US、en），中文等其它语言会从列表里删掉；
    拼写检查词典、「不翻译的语言」也只留英文。
  - Chrome 只清缓存子目录，不删除书签、密码、登录状态。
  - Claude Code 卸载默认保留配置和会话数据；只有勾选“同时删除配置和会话数据”
    （脚本版是加 -RemoveData）才会删除。
  - Claude Desktop 卸载不会删除聊天记录和项目文件。
  - Claude 安装/卸载需要 Windows 自带的 winget。
  - 不会删除中文语言包。

脚本版备份位置：
  %USERPROFILE%\.xiaochuan-env\backups\<时间>\
    chrome-files\           修改前的 Chrome Local State 和 Preferences
    settings-snapshot.txt   修改前的时区、语言、输入法和定位开关
