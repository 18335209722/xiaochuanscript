小川 Clash Verge 安装助手 · Windows 版 1.0.0 · 使用说明

这是一个独立的脚本（clash-verge.bat + clash-verge.ps1，两个文件要放在同一个目录），
和 xiaochuan-env.bat、chrome-profile.bat 互不影响。

作用：
  检查这台电脑有没有装 Clash Verge Rev（https://github.com/clash-verge-rev/clash-verge-rev）。
    已经装了：不再安装（桌面上没有 Clash Verge 快捷方式的话，会补建一个）。
    没有装：自动找到适合本机的最新版，下载、校验、安装，在桌面建快捷方式图标，然后打开。

执行时能看到进度：
  一共 5 步，窗口里会显示「第 几/5 步」：
    1 检查有没有装  2 查找最新版  3 下载安装包  4 安装  5 建桌面快捷方式并打开
  下载时会显示进度条和百分比，开始下载前会显示安装包大小。

运行：
  双击 clash-verge.bat                检查，没装就安装并打开
  clash-verge.bat -DryRun             演练：只显示将要下载哪个安装包
  clash-verge.bat -DownloadOnly       只下载并校验安装包（保存到「下载」文件夹），不安装
  clash-verge.bat -Help               显示说明

  安装时 Windows 会弹一次 UAC，点「是」。不需要手动「以管理员身份运行」。

会装哪个安装包（自动判断）：
  普通电脑（x64）：Clash.Verge_版本_x64-setup.exe
  ARM 电脑：       Clash.Verge_版本_arm64-setup.exe

下载和校验：
  - 先从 GitHub 官方地址下载；失败或太慢（连续 20 秒低于约 100KB/s）时自动换镜像；
    都不行最后再回到官方地址慢慢下，断了会自动续传。
  - 下载完会和 GitHub 官方公布的校验值（SHA-256）比对，一致才安装。
    镜像不是官方的，所以镜像下载的文件必须校验一致才会用；拿不到官方校验值时不走镜像。
  - 下载失败时会给出手动下载的地址。

说明：
  - 安装是静默安装，不用一步步点「下一步」；静默安装没成功时会自动改为打开普通安装界面。
  - 桌面快捷方式叫「Clash Verge」；桌面上已经有的话不会重复建。
  - 装完会有「执行后检查」：√ 表示已安装、桌面有快捷方式、已打开。
  - 本脚本只负责安装和打开，不会导入订阅，也不会改 Clash Verge 的任何设置。
