小川环境助手 · macOS / Linux 版 1.2.0 · 使用说明

运行（macOS 和 Linux 是同一个脚本，会自动识别系统）：
  macOS：在访达里双击 xiaochuan-env.command 即可打开菜单。
         第一次如果提示「无法打开」，右键点它 > 打开；
         如果提示没有权限，在终端执行一次：chmod +x xiaochuan-env.command
  终端：
    bash xiaochuan-env.sh                    交互菜单（输入 a 一键执行）
    bash xiaochuan-env.sh --all              直接执行：清缓存 + Chrome + 时区 + 语言 + 关定位
    bash xiaochuan-env.sh --all --dry-run    演练，只显示将要做的事
    bash xiaochuan-env.sh status             检查当前状态
    bash xiaochuan-env.sh --help             全部参数

  不要在前面加 sudo。脚本会在需要时自己申请管理员权限，只要输一次本机登录密码
  （输入时屏幕上不显示，输完按回车）。即使加了 sudo，脚本也会自动改回你自己的身份执行。

功能：
  1. 清理 Claude Code 缓存、日志、临时文件（--cache）
  2. 可选清理 Claude Code 会话历史（--history）
  3. 清理 Chrome 缓存，把 Chrome 语言设为 en-US，并关闭 Chrome 定位（--chrome）
  4. 修改时区为 America/Los_Angeles（--timezone）
  5. 修改系统语言/区域为 en-US，并清空键盘布局只留美式键盘（--language）
  6. 关闭系统定位服务（--location）
  7. 安装 / 卸载 Claude Code 和 Claude Desktop
     （install-code / uninstall-code / install-desktop / uninstall-desktop）

状态检查：
  菜单顶部和每次执行结束后都会显示当前状态：
    ✓ 表示这一项已经达标，✗ 表示还没达标。
  时区这一项只有「时区正确」并且 macOS 的「自动设置时区」已关闭才算 ✓。
  Chrome 定位要每个个人资料都是「不允许网站查看我的位置」才算 ✓。
  macOS 的系统定位开关要管理员权限才读得到：没输过密码时状态里显示「现在读不到」，
  执行「关闭系统定位」后会在「执行结果」里核对。

执行方式（多种方式逐个尝试 + 执行结果）：
  - 每次执行一开始就申请管理员权限（输一次密码）。
  - 每一项都准备了多种做法：一种不行就自动换下一种，每试一种都读回实际结果核对，
    成功才停。例如时区：系统命令 > 直接改 /etc/localtime 链接 > 删掉重建链接。
    普通方式删不掉的文件、改不了的 Chrome 配置，会用管理员权限再试。
  - 每次执行的最后都有一份「执行结果」，对你选中的每一项列出绿色的 ✓ 或红色的 ✗；
    没有完成的项目用红色高亮，并写着「没有完成」。
    最后一行是总结果：全部完成是绿底，有没完成的是红底，并写明有几行没有完成。

注意：
  - 当前账户必须是管理员；语言需要注销或重启后生效。
  - macOS 会同时关闭「自动设置时区」，否则时区会被定位改回去。
  - 关闭系统定位：macOS 是 系统设置 > 隐私与安全性 > 定位服务 的总开关；
    Linux 是 GNOME 的「定位服务」开关，并屏蔽 GeoClue 定位服务
    （恢复：sudo systemctl unmask geoclue.service）。
    新版 macOS 可能不让脚本改这个开关：这时「执行结果」里会标红，请按提示手动关闭。
  - 关闭 Chrome 定位 = chrome://settings/content/location 改成「不允许网站查看我的位置」，
    以前单独允许过定位的网站也会一并清掉；每个个人资料都会改。
  - Claude Code 必须完全退出，否则拒绝清理（可加 --force 跳过检查）。
  - Chrome 在运行时会先自动把它关闭（先正常退出，标签页下次可恢复；退不掉再强制结束），
    然后再清理和改语言。执行前请先保存好网页里没提交的内容。
  - Chrome 的语言列表会改成只有英文（en-US、en），中文等其它语言会从列表里删掉；
    拼写检查词典、「不翻译的语言」也只留英文。
  - Chrome 只清缓存子目录，不删除书签、密码、登录状态。
  - 会话历史删除后无法恢复，--all 不包含它，需要单独加 --history。
  - Claude Code 卸载默认保留配置和会话数据；只有加 --remove-data 才会删除。
  - Claude Desktop 只支持 macOS，需要 Homebrew；卸载不会删除聊天记录和项目文件。
  - 改语言时会清空键盘布局 / 输入法列表，只留美式键盘（和 Windows 版一致）；
    中文输入法本身不会被卸载，需要时到系统设置里重新添加。
  - 不会删除中文语言包。

备份位置：
  ~/.xiaochuan-env/backups/<时间>/
    chrome-files/           修改前的 Chrome Local State 和 Preferences
    settings-snapshot.txt   修改前的时区、语言、键盘布局和定位开关
    keyboard/               修改前的输入法配置文件
