小川重启后助手 · macOS / Linux 版 1.0.0 · 使用说明

这是一个独立的脚本（after-reboot.sh），和 xiaochuan-env.sh 互不影响。

什么时候执行：
  先用 xiaochuan-env.sh 改好时区、语言并重启电脑，重启之后再执行本脚本。

作用（一次做两件事）：
  1. Chrome 个人资料
     新建一个「不登录 Google 账号」的 Chrome 个人资料，名字叫 claude，并用它打开 Chrome。
     相当于手动点：Chrome 右上角头像 > 添加新的个人资料 > 保持未登录状态 > 起名 claude。
     用户以前登录过的那个个人资料不会被改动或删除，只是不再用它打开。
  2. Clash Verge Rev（https://github.com/clash-verge-rev/clash-verge-rev）
     已经装了：不再安装。
     没有装：自动找到适合本机的最新版，下载、校验、安装，然后打开。

  两件事互不影响：前一件没成功，后一件照样会做。

运行：
  macOS：在访达里双击 after-reboot.command。
         第一次如果提示「无法打开」，右键点它 > 打开；
         如果提示没有权限，在终端执行一次：chmod +x after-reboot.command
  终端：
    bash after-reboot.sh                 两件事都做
    bash after-reboot.sh --name 名字     Chrome 个人资料换一个名字（默认 claude）
    bash after-reboot.sh --only-chrome   只做 Chrome 个人资料
    bash after-reboot.sh --only-clash    只做 Clash Verge
    bash after-reboot.sh --dry-run       演练：只显示将要做的事，不做任何修改
    bash after-reboot.sh --help          显示说明

  不要加 sudo。只有需要安装 Clash Verge 时才会用到管理员权限：
  Linux 上会要求输入一次本机登录密码；macOS 一般不需要密码（当前账户不是管理员时才会要）。

执行时能看到进度：
  窗口里会显示「第 几/6 步」：
    1 Chrome 个人资料
    2 检查有没有装 Clash Verge   3 查找最新版   4 下载安装包   5 安装   6 打开并检查
  Clash Verge 已经装了的话，第 3～6 步会跳过。
  下载时会显示进度条和百分比，开始下载前会显示安装包大小。

执行结果：
  执行的最后有一份「执行结果」：完成的项目是绿色 ✓；没有完成的项目用红色高亮，并写着「没有完成」。
  最后一行是总结果：全部完成是绿底，有没完成的是红底，并写明有几行没有完成。

Chrome 个人资料的说明：
  - 第一次执行会新建个人资料；以后再执行不会重复新建，而是直接打开已经建好的那个。
  - 新个人资料不登录任何账号，语言只有英文（en-US、en），定位默认关闭（不允许网站查看位置）。
  - Chrome 会记住最后使用的个人资料，所以之后直接点 Chrome 图标也会进入 claude，
    不会再回到以前登录的那个。想回去的话点 Chrome 右上角头像切换即可。
  - Chrome 开着或关着都可以执行。

Clash Verge 的说明：
  - 会装哪个安装包（自动判断）：
      macOS  Apple 芯片：Clash.Verge_版本_aarch64.dmg      Intel 芯片：Clash.Verge_版本_x64.dmg
      Linux  Debian / Ubuntu：.deb                          Fedora / openSUSE 等：.rpm
  - 先从 GitHub 官方地址下载；失败或太慢（连续 20 秒低于约 100KB/s）时自动换镜像；
    都不行最后再回到官方地址慢慢下，断了会自动续传。
  - 下载完会和 GitHub 官方公布的校验值（SHA-256）比对，一致才安装。
    镜像不是官方的，所以镜像下载的文件必须校验一致才会用；拿不到官方校验值时不走镜像。
  - 下载失败时会给出手动下载的地址。
  - macOS 第一次打开 Clash Verge 时，它可能会要求输入密码来安装自己的系统服务，按提示操作即可。
  - 本脚本只负责安装和打开，不会导入订阅，也不会改 Clash Verge 的任何设置。
