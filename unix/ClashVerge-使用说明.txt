小川 Clash Verge 安装助手 · macOS / Linux 版 1.0.0 · 使用说明

这是一个独立的脚本（clash-verge.sh），和 xiaochuan-env.sh、chrome-profile.sh 互不影响。

作用：
  检查这台电脑有没有装 Clash Verge Rev（https://github.com/clash-verge-rev/clash-verge-rev）。
    已经装了：什么都不做。
    没有装：自动找到适合本机的最新版，下载、校验、安装，然后打开。

执行时能看到进度：
  一共 5 步，窗口里会显示「第 几/5 步」：
    1 检查有没有装  2 查找最新版  3 下载安装包  4 安装  5 打开并检查
  下载时会显示进度条和百分比，开始下载前会显示安装包大小。

运行：
  macOS：在访达里双击 clash-verge.command。
         第一次如果提示「无法打开」，右键点它 > 打开；
         如果提示没有权限，在终端执行一次：chmod +x clash-verge.command
  终端：
    bash clash-verge.sh                  检查，没装就安装并打开
    bash clash-verge.sh --dry-run        演练：只显示将要下载哪个安装包
    bash clash-verge.sh --download-only  只下载并校验安装包（保存到「下载」文件夹），不安装
    bash clash-verge.sh --help           显示说明

  不要加 sudo。Linux 上安装时会要求输入一次本机登录密码；
  macOS 一般不需要密码（当前账户不是管理员时才会要）。

会装哪个安装包（自动判断）：
  macOS  Apple 芯片：Clash.Verge_版本_aarch64.dmg      Intel 芯片：Clash.Verge_版本_x64.dmg
  Linux  Debian / Ubuntu：.deb                          Fedora / openSUSE 等：.rpm

下载和校验：
  - 先从 GitHub 官方地址下载；失败或太慢（连续 20 秒低于约 100KB/s）时自动换镜像；
    都不行最后再回到官方地址慢慢下，断了会自动续传。
  - 下载完会和 GitHub 官方公布的校验值（SHA-256）比对，一致才安装。
    镜像不是官方的，所以镜像下载的文件必须校验一致才会用；拿不到官方校验值时不走镜像。
  - 下载失败时会给出手动下载的地址。

说明：
  - 装完会有「执行后检查」：✓ 表示已安装、已打开。
  - macOS 第一次打开 Clash Verge 时，它可能会要求输入密码来安装自己的系统服务，按提示操作即可。
  - 本脚本只负责安装和打开，不会导入订阅，也不会改 Clash Verge 的任何设置。
