小川 Chrome 个人资料助手 · macOS / Linux 版 1.0.0 · 使用说明

这是一个独立的脚本（chrome-profile.sh），和 xiaochuan-env.sh 互不影响。

作用：
  新建一个「不登录 Google 账号」的 Chrome 个人资料，名字叫 claude，并用它打开 Chrome。
  相当于手动点：Chrome 右上角头像 > 添加新的个人资料 > 保持未登录状态 > 起名 claude。
  用户以前登录过的那个个人资料不会被改动或删除，只是不再用它打开。

什么时候执行：
  先用 xiaochuan-env.sh 改好时区、语言并重启电脑，重启之后再执行本脚本。

运行：
  macOS：在访达里双击 chrome-profile.command。
         第一次如果提示「无法打开」，右键点它 > 打开；
         如果提示没有权限，在终端执行一次：chmod +x chrome-profile.command
  终端：
    bash chrome-profile.sh                 新建 / 打开名字叫 claude 的个人资料
    bash chrome-profile.sh --name 名字     换一个名字
    bash chrome-profile.sh --dry-run       演练，只显示将要做的事
    bash chrome-profile.sh --help          显示说明

  不需要管理员权限，不要加 sudo。

说明：
  - 第一次执行会新建个人资料；以后再执行不会重复新建，而是直接打开已经建好的那个。
  - 新个人资料不登录任何账号，语言只有英文（en-US、en）。
  - 执行完会有「执行后检查」：✓ 表示 Chrome 已经用这个个人资料打开并且名字正确。
  - Chrome 会记住最后使用的个人资料，所以之后直接点 Chrome 图标也会进入 claude，
    不会再回到以前登录的那个。想回去的话点 Chrome 右上角头像切换即可。
  - Chrome 开着或关着都可以执行。
