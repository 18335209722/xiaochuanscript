小川 Claude 命令行安装助手 · Windows 版 1.0.0 · 使用说明

这是一个独立的脚本（install-claude.bat + install-claude.ps1，两个文件要放在同一个目录），
和 xiaochuan-env.bat、enable-ssh.bat 等互不影响。

作用：
  下载并安装 Claude Code 命令行。装完之后，在命令窗口（PowerShell / cmd，
  以及用 Termius、ssh 远程登录进来的窗口）里直接输入 claude 就能用。

  一次做三件事：
    1. 下载并安装 Claude Code。用的是 Anthropic 官方安装脚本（https://claude.ai/install.ps1），
       装到 用户目录\.local\bin\claude.exe，官方脚本会核对安装包的校验值（SHA-256）。
       官方安装脚本用不了、而电脑上有 npm（Node.js）时，改用 npm install -g @anthropic-ai/claude-code。
       已经装了就跳过。
    2. 把 用户目录\.local\bin 加进这个用户的 PATH，这样任何命令窗口里都能直接输入 claude。
    3. 检查 claude 能正常运行，显示版本号和用法。

  不需要管理员权限，不会弹 UAC。只装给当前登录的这个 Windows 用户。
  重复执行没有副作用：已经做好的步骤会直接跳过。

运行：
  双击 install-claude.bat               安装 Claude Code，并让命令窗口里能直接输入 claude
  install-claude.bat -Update            已经装了的话，升级到最新版
  install-claude.bat -Status            只查看现在的状态，不做任何修改
  install-claude.bat -DryRun            演练：只显示将要做的事，不做任何修改
  install-claude.bat -Help              显示说明

  也可以在远程登录（SSH / Termius）进来的窗口里执行，效果一样。

装完怎么用：
  1. 新开一个命令窗口。执行脚本之前就开着的窗口不认新的 PATH，要关掉重开；
     SSH / Termius 远程登录的要断开重新登录。
  2. 用 cd 进到要干活的目录，输入 claude。
  3. 第一次用要登录：按屏幕提示在浏览器里登录 Claude 账户。
     远程登录时这台电脑弹不出浏览器：把屏幕上显示的网址复制到自己电脑的浏览器里打开，
     登录后把网页给的代码粘贴回命令窗口。
  常用命令：
      claude --version      看版本
      claude update         升级到最新版
      claude -p "问题"      只问一句就退出

其他说明：
  - 网络：安装时要能访问 claude.ai 和 downloads.claude.ai（安装包 200 多 MB）；
    使用时要能访问 Anthropic 的服务（claude.ai / api.anthropic.com）。装不上的时候，最常见的原因就是网络。
  - 远程登录的账户要和执行本脚本的账户是同一个 Windows 用户；别的用户要用的话，登录那个用户再执行一次。
  - 没有装 Git for Windows 也能用。启动 claude 时如果提示需要 git-bash，到 https://git-scm.com/download/win 装一下。
  - 卸载：删除 用户目录\.local\bin\claude.exe 和 用户目录\.local\share\claude 这个目录
    （npm 装的用 npm uninstall -g @anthropic-ai/claude-code）。登录信息和设置在 用户目录\.claude 里。

执行结果：
  执行的最后有一份「执行结果」：完成的项目是绿色 √；没有完成的项目用红色高亮，并写着「没有完成」。
  最后一行是总结果：全部完成是绿底，有没完成的是红底，并写明有几行没有完成。
