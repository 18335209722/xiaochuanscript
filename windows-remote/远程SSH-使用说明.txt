小川远程 SSH 助手 · Windows 版 1.1.0 · 使用说明

这是一个独立的脚本（enable-ssh.bat + enable-ssh.ps1，两个文件要放在同一个目录），
和 xiaochuan-env.bat、after-reboot.bat 互不影响。

作用：
  让这台 Windows 电脑可以被 SSH 连接。打开之后，就能从别的电脑（Windows / macOS / Linux 都行）
  用 ssh 命令登录这台电脑，远程执行命令行。

  一次做五件事：
    1. 安装 OpenSSH 服务端（Windows 自带的可选功能）。已经装了就跳过。
       系统自带的装不上时（比如 Windows 更新被禁用），自动改从 GitHub 官方
       （https://github.com/PowerShell/Win32-OpenSSH）下载安装包安装。
    2. 启动 sshd 服务，并设为开机自动启动（重启电脑之后不用再执行本脚本）。
    3. Windows 防火墙放行 SSH 端口（默认 TCP 22，专用 / 公用网络都放行）。
    4. 登录设置：把远程登录后的命令行设为 PowerShell（用 Termius 之类的工具登录进来，直接就是 PowerShell，
       不再是 cmd）；可选写入公钥（免密码登录）。
    5. 检查 SSH 端口确实通了，并显示从别的电脑连接要用的命令。

  重复执行没有副作用：已经做好的步骤会直接跳过或保持原样。

运行：
  双击 enable-ssh.bat                   打开 SSH，用 Windows 账户的密码登录；远程登录后的命令行设为 PowerShell
  enable-ssh.bat -PubKey "ssh-ed25519 AAAA... 备注"
                                        同时写入公钥，可以免密码登录（也可以给 .pub 文件的路径）
  enable-ssh.bat -Shell cmd             远程登录后的命令行恢复为 cmd（Windows 默认）
  enable-ssh.bat -Shell keep            不改动远程登录后的命令行
  enable-ssh.bat -Shell powershell      强制设为 PowerShell（之前手动设成别的 shell 时用）
  enable-ssh.bat -Status                只查看现在的状态和连接命令，不做任何修改
  enable-ssh.bat -Off                   关闭：停止 sshd 服务并删除防火墙规则
  enable-ssh.bat -DryRun                演练：只显示将要做的事，不做任何修改
  enable-ssh.bat -Help                  显示说明

  不需要手动「以管理员身份运行」。执行时 Windows 会弹一次 UAC，点「是」，之后在新开的窗口里执行。

怎么连接：
  执行完之后，窗口里会列出连接命令，形如：
      ssh 用户名@192.168.1.23
  在另一台电脑的终端里输入这条命令，再输入密码，就登录进来了。
  只想远程执行一条命令的话，把命令写在后面：
      ssh 用户名@192.168.1.23 hostname

  - 用户名：登录 Windows 的那个账户名（窗口里会显示）。
  - 密码：这个 Windows 账户的登录密码。用微软账户登录 Windows 的，是微软账户的密码，不是 PIN 码。
    账户没有设密码的话不能用密码登录：要先给账户设一个密码，或者用 -PubKey 写入公钥。
  - 192.168 / 10 开头的地址只有在同一个局域网（同一个路由器 / WiFi）里才能连。
    两台电脑不在同一个网络时，可以两边都装 Tailscale 之类的组网软件，用 100 开头的那个地址连。
  - 电脑睡眠或关机时连不上。需要长期远程的话，在「设置 > 系统 > 电源」里把睡眠改成「从不」。

免密码登录（公钥）：
  在「要连过来的那台电脑」上执行 ssh-keygen -t ed25519（一路回车），
  然后把 ~/.ssh/id_ed25519.pub 这个文件里的那一行内容拿过来，在这台电脑上执行：
      enable-ssh.bat -PubKey "ssh-ed25519 AAAA... 备注"
  - 要用的是 .pub 结尾的公钥。私钥（没有 .pub 的那个文件）不能给别人，脚本发现给的是私钥会拒绝。
  - 可以多次执行来加多个公钥；同一个公钥不会重复写入。
  - 公钥写在 用户目录\.ssh\authorized_keys；账户是管理员时还会写到
    C:\ProgramData\ssh\administrators_authorized_keys（管理员登录时 sshd 只认这个文件），并设好它要求的权限。

远程登录后的命令行（PowerShell）：
  Windows 的 SSH 默认登录进来是 cmd。本脚本默认把它换成 PowerShell，这样用 Termius、ssh 命令登录进来
  直接是 PowerShell（提示符是 PS C:\Users\用户名>）。
  - 对所有通过 SSH 登录这台电脑的账户都生效；不影响在这台电脑上本地打开的命令窗口。
  - 改完不用重启 sshd，但已经连着的会话不会变，要断开重新登录。
  - 之前手动设成了别的 shell（比如 PowerShell 7、Git Bash）的话，脚本不会覆盖；
    要强制换成 PowerShell 用 -Shell powershell。
  - 想改回 cmd：enable-ssh.bat -Shell cmd。
  - 已经打开过 SSH 的电脑，再双击执行一次 enable-ssh.bat 就会换成 PowerShell
    （fix-ssh-login.bat 也会做同样的设置）。

执行结果：
  执行的最后有一份「执行结果」：完成的项目是绿色 √；没有完成的项目用红色高亮，并写着「没有完成」。
  最后一行是总结果：全部完成是绿底，有没完成的是红底，并写明有几行没有完成。

其他说明：
  - 脚本不会修改 sshd 的配置文件（C:\ProgramData\ssh\sshd_config）。那里面改过端口的话，
    防火墙放行的和显示的连接命令都会用改过之后的端口。
  - 防火墙规则名叫 Xiaochuan-SSH-In-TCP。只处理 Windows 自带的防火墙；
    装了别的安全软件（360、火绒等）并且拦截了入站连接的话，要在那个软件里另外放行。
  - 从 GitHub 下载的安装包，要有微软的有效数字签名、或者和 GitHub 官方公布的校验值（SHA-256）一致才会安装；
    镜像下载的文件同样要通过这个检查。
  - -Off 只是停止服务并删除防火墙规则，不会卸载 OpenSSH，也不会删除写入过的公钥；
    再执行一次 enable-ssh.bat 就能重新打开。
  - 打开 SSH 之后，知道这台电脑账户密码的人就能远程登录它。请给 Windows 账户设一个不容易猜到的密码，
    不需要远程的时候用 -Off 关掉。
